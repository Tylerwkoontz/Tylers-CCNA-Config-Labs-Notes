# CCNA Troubleshooting Drills (Break-Fix)

This section holds structured troubleshooting exercises. Each scenario presents a realistic network symptom, verification output, and guided diagnostic steps.

---

## 🛠️ Scenario Categories
* **Layer 1 & Layer 2 Issues**: Cable faults, speed/duplex mismatch, errdisable, port security, VLAN trunking native mismatch, STP blocking.
* **Layer 3 Addressing & Routing**: Incorrect subnet mask, overlapping subnets, gateway misconfiguration, static route next-hop invalid, OSPF neighbor stuck in INIT/EXSTART.
* **IP Services & Security**: ACL blocking legitimate traffic, DHCP scope exhaustion, NAT overload misconfig.
