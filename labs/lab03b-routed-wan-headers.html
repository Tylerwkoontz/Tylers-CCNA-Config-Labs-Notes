Lab 03B: Multi-Hop Routed WAN & Layer 2 Header Transformation

Curriculum Focus: Cisco Press Official Cert Guide Vol 1, Part I (Chapter 3) • Topics: Multi-Hop Routing, Ethernet LAN vs Point-to-Point WAN Framing, Layer 2 Header Transformation, and IP Header Invariance.

🗺️ Topology, Addressing & Initial State

Scenario: You are deploying an enterprise branch connection linking Site A (10.1.1.0/24) to Site B (10.1.2.0/24) across a Point-to-Point routed WAN link (10.1.12.0/30). You must configure router interfaces, establish static routing between R1 and R2, and trace how Layer 2 encapsulation morphs across each link while Layer 3 IP headers remain unchanged.

Initial Baseline State: Routers R1 and R2 have default factory configurations with all interfaces shutdown. PC1 and PC2 have IP addresses configured on their local interfaces.

📋 Engineering Requirements

Configure the routers and trace multi-hop packet delivery and framing transformations.

1. Router Hostnames & Usability:

  • Configure device hostname R1 on Router 1 and R2 on Router 2.
  • On both routers, configure console line 0 with logging synchronous and exec-timeout 0 0.

2. Interface Addressing & Physical Enablement:

  • On R1, configure IPv4 addresses and descriptions on GigabitEthernet0/1 (Site A LAN) and GigabitEthernet0/0 (WAN to R2). Enable both interfaces and bring the interface up.
  • On R2, configure IPv4 addresses and descriptions on GigabitEthernet0/1 (Site B LAN) and GigabitEthernet0/0 (WAN to R1). Enable both interfaces and bring the interface up.

3. IPv4 Static Routing Across the WAN:

  • On R1, configure an IPv4 static route to reach Site B LAN (10.1.2.0/24) via R2's WAN IP (10.1.12.2).
  • On R2, configure an IPv4 static route to reach Site A LAN (10.1.1.0/24) via R1's WAN IP (10.1.12.1).

4. End-to-End Tracing & Header Transformation:

  • Initiate an ICMP ping from PC1 to PC2 (10.1.2.20) and verify 100% bidirectional reachability.
  • Execute a traceroute from PC1 to PC2 and record each intermediate router hop and TTL decrement.
  • Analyze how Layer 2 encapsulation changes across the 3 segments (LAN 1 → WAN Link → LAN 2) while Layer 3 Source IP (10.1.1.10) and Destination IP (10.1.2.20) remain invariant.

5. Configuration Persistence:

  • Save the active running configuration to NVRAM on both routers.

🔬 Architectural Breakdown & Design Logic

This lab reinforces core Volume 1 Chapter 3 WAN concepts: how routers interconnect disparate Layer 2 data links and provide end-to-end routing.

1. Why Layer 2 Headers Are Stripped at Every Router

A Layer 2 Ethernet frame exists solely to deliver a payload across a single local physical medium (collision domain / broadcast domain). When a frame arrives at a router:

  • The router strips and discards the Layer 2 header because that header has completed its job of getting the packet across the first link.
  • The router inspects the Layer 3 IP packet to determine the next hop.
  • It builds a completely new Layer 2 header tailored to the outgoing physical media (e.g. Ethernet, Serial HDLC, or Frame Relay) before transmission.

2. The Golden Rule of IP Header Invariance

Notice that throughout the entire journey across multiple routers, the Source IP (`10.1.1.10`) and Destination IP (`10.1.2.20`) never change (unless Network Address Translation / NAT is performed).

The only IP header fields that change are:

  • TTL (Time-to-Live): Decremented by 1 at each router.
  • Header Checksum: Recalculated at each router due to the modified TTL.
