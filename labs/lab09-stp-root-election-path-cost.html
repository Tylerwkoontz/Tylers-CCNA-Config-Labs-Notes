🏢 Enterprise Scenario & Physical Topology

You are the lead network engineer for an enterprise branch campus. Three Cisco Catalyst distribution/access switches (SW1, SW2, and SW3) are deployed in a redundant triangle mesh to eliminate any single point of failure for access clients PC-A and PC-B.

Without Spanning Tree Protocol (IEEE 802.1D / 802.1w), this physical ring would cause catastrophic broadcast storms, MAC address table thrashing (flapping), and multiple duplicate frame copies.

By default, all switches boot with the standard bridge priority of 32768 (plus VLAN 1 system ID = 32769). Because all priorities are equal, the switch with the lowest factory MAC address randomly wins the Root Bridge election. You must take full deterministic control over the topology by manually designating primary/secondary root roles and engineering specific port paths.

  • Configure the hostnames on all three switches as SW1, SW2, and SW3.
  • Configure console line line con 0 on all switches with logging synchronous and exec-timeout 0 0 to prevent console output interruptions during STP election events.

2. Deterministic Root Bridge Hierarchy (VLAN 1)

  • On SW1, configure the Spanning Tree priority for VLAN 1 to 4096 so it is guaranteed to win the Root Bridge election over any default switch.
  • On SW2, configure the Spanning Tree priority for VLAN 1 to 8192 so it acts as the designated Secondary Root Bridge in the event of SW1 failure.
  • Leave SW3 at the default priority of 32768.

3. Baseline STP State Verification & Analysis

  • Verify on SW1 that all active switchports are in the Designated (Desg) role and Forwarding (FWD) state with a path cost of 0 to the root.
  • Verify on SW2 and SW3 that their direct links to SW1 (Gi0/1 on SW2 and Gi0/1 on SW3) are selected as Root Ports (Root) with a path cost of 4.
  • Verify that on the segment connecting SW2 Gi0/3 and SW3 Gi0/3, SW2 Gi0/3 becomes the Designated Port (due to lower Bridge ID) and SW3 Gi0/3 is placed into the Alternate/Blocking (Altn/BLK) state.

4. Path Cost Tuning & Traffic Re-Routing

  • The network architect wants traffic from SW3 destined for the root to transit through SW2 instead of using the direct link Gi0/1.
  • On SW3, increase the Spanning Tree port cost of interface GigabitEthernet0/1 to 10 (using spanning-tree cost 10 or spanning-tree vlan 1 cost 10).
  • Verify that SW3 recalculates its Root Path Costs:
    • Direct path via Gi0/1 = Cost 10.
    • Indirect path via Gi0/3 (SW3 → SW2 → SW1) = Cost 4 + Cost 4 = Cost 8.
  • Confirm that SW3 Gi0/3 immediately transitions from Alternate/Blocking to Root Port (Forwarding), and SW3 Gi0/1 becomes the new Alternate Port (Blocking).

📖 Wendell Odom OCG Vol 1 Chapter 9: Core STP Architecture

Spanning Tree Protocol (IEEE 802.1D) prevents Layer 2 loops by building a single loop-free logical path (a spanning tree) through a physically redundant switched Ethernet network.

1. The 3-Step Spanning Tree Election Algorithm

STP converges through three sequential deterministic steps:

  • Step 1: Elect One Root Bridge per Broadcast Domain (VLAN)
    Every switch initially claims to be the root by sending Hello BPDUs. The switch with the lowest Bridge ID (BID) wins.
    All active interfaces on the Root Bridge are placed in the Designated role and Forwarding state.
  • Step 2: Elect One Root Port (RP) on Every Non-Root Switch
    Each non-root switch evaluates all its active ports and selects the single port with the lowest cumulative Root Path Cost to reach the Root Bridge.
    The Root Port is always in the Forwarding state.
  • Step 3: Elect One Designated Port (DP) on Every LAN Segment (Collision Domain)
    On each link between two switches, the switch that advertises the lowest Root Path Cost onto that segment wins the Designated Port role (enters Forwarding state).
    The losing port on the link is placed into the Alternate Port (Blocking / Discarding) state to break the loop.

2. Bridge ID Structure & The 802.1t System ID Extension

The Bridge ID is an 8-byte (64-bit) value originally composed of a 2-byte Priority and 6-byte Base MAC address. IEEE 802.1t redefined the Priority field to support PVST+ (Per-VLAN Spanning Tree):

Field Length Description / Valid Values
Bridge Priority 4 bits Configurable in multiples of 4096 (0, 4096, 8192, 12288, ..., 61440). Default is 32768.
System ID Extension 12 bits Carries the VLAN ID (1 to 4094). Allows a single MAC address to be shared across all VLAN instances.
MAC Address 48 bits (6 bytes) The switch's unique burned-in base MAC address. Used as the ultimate tiebreaker.
Exam Trap: When inspecting show spanning-tree, the priority reported is Priority = Configured Priority + VLAN ID. For example, default VLAN 1 priority displays as 32769 (32768 + 1). Priority 4096 displays as 4097.

3. STP Port Costs (Old vs New IEEE Standards)

Switches add the incoming port's configured cost to the cumulative Root Path Cost contained in received BPDUs:

Speed / Interface Type IEEE 802.1D-1998 (16-bit / Classic) IEEE 802.1D-2004 / 802.1w (32-bit / RSTP)
10 Mbps (Ethernet) 100 2,000,000
100 Mbps (FastEthernet) 19 200,000
1 Gbps (GigabitEthernet) 4 20,000
10 Gbps (TenGigabitEthernet) 2 2,000

4. STP Tiebreaker Hierarchy (When Costs Tie)

If multiple paths have identical Root Path Costs, switches resolve the tie using this strict 4-step hierarchy:

  1. Lowest Cumulative Root Path Cost (Lowest cost to root wins).
  2. Lowest Sender Bridge ID (Neighbor with lowest BID wins).
  3. Lowest Sender Port Priority (Configurable in increments of 16, default 128).
  4. Lowest Sender Internal Port Number (Neighbor's lower interface number, e.g., Gi0/1 beats Gi0/2).

5. Classic STP (802.1D) Port States & Convergence Timers

Port State Forwards Frames? Learns MACs? Processes BPDUs? Duration / Timer
Blocking ❌ No ❌ No ✅ Yes (Receives only) Indefinite (or 20s MaxAge on failure)
Listening ❌ No ❌ No ✅ Yes (Sends & Receives) 15 Seconds (Forward Delay)
Learning ❌ No ✅ Yes (Populates MAC table) ✅ Yes (Sends & Receives) 15 Seconds (Forward Delay)
Forwarding ✅ Yes (Full normal operation) ✅ Yes ✅ Yes (Sends & Receives) Indefinite
Disabled ❌ No ❌ No ❌ No Port administratively shut down
Classic STP Convergence Calculation:
Direct Link Failure = Listening (15s) + Learning (15s) = 30 seconds.
Indirect Link Failure = Max Age (20s) + Listening (15s) + Learning (15s) = 50 seconds.

Command Diagnostic Purpose
