🏢 Enterprise Scenario & Physical Topology

You are tuning Layer 2 path selection and convergence characteristics between core switch SW1 and access switch SW2. Two parallel GigabitEthernet links (Gi0/1 and Gi0/2) interconnect the switches for link redundancy.

Because both parallel links connect the exact same two switches with identical Gigabit port costs (Cost = 4) and identical Root Bridge IDs, the first two STP tiebreakers (Root Path Cost and Sender Bridge ID) result in a dead tie.

In this lab, you will analyze why SW2 places interface Gi0/2 into the Alternate/Blocking state by default due to the Sender Port ID advertised in SW1's BPDUs. You will then manipulate the Port Priority on SW1 Gi0/2 to invert active forwarding paths without altering interface costs, and examine how tuning STP timers (Hello Time, Max Age, Forward Delay) affects network convergence.

Tiebreaker Step Link 1 (Gi0/1) Parameter Link 2 (Gi0/2) Parameter Winner / Decision
1. Root Path Cost Cost 4 Cost 4 Tie (4 = 4)
2. Sender Bridge ID SW1 (4097.5254.0012.3456) SW1 (4097.5254.0012.3456) Tie (Same Switch)
3. Default Sender Port Priority / ID 128.2 (Priority 128, Port 2) 128.3 (Priority 128, Port 3) Gi0/1 Wins (128.2 < 128.3 → Gi0/2 Blocked)
4. Tuned Sender Port Priority (SW1) 128.2 (Unchanged) 64.3 (Tuned to 64) Gi0/2 Wins! (64.3 < 128.2 → Gi0/1 Blocked)
⚠️ Key Concept: STP tiebreaker #3 and #4 evaluate the sender's port priority and internal port number (the neighbor switch sending BPDUs), NOT the local switch's port numbers. Therefore, to change which port SW2 blocks, you must configure the port priority on SW1!

🔬 Deep-Dive: The Mechanics of STP Port Priority & Port ID

When a non-root switch connects to an upstream switch via multiple parallel links, the root path cost through all parallel links is identical. In Cisco IOS, the switch uses the Port ID advertised by the upstream neighbor in its BPDUs to break the tie.

1. Structure of the 16-Bit Port ID

Every switch interface has a 16-bit Port ID formatted as [Port Priority].[Internal Port Number]:

  • Port Priority (8 bits): Configurable in increments of 16 (0, 16, 32, 48, 64, 80, 96, 112, 128, ..., 240). Default value is 128.
  • Internal Port Number (8 bits): Assigned sequentially by Cisco IOS based on the internal slot/port number (e.g. Gi0/0 = Port 1, Gi0/1 = Port 2, Gi0/2 = Port 3, etc.).
Why did SW2 block Gi0/2 originally?
SW1 sent BPDUs out Gi0/1 with Port ID 128.2.
SW1 sent BPDUs out Gi0/2 with Port ID 128.3.
Because 128.2 < 128.3, SW2 selected Gi0/1 as Root Port and placed Gi0/2 into Alternate/Blocking!

2. How Port Priority Tuning Works

When you configure spanning-tree port-priority 64 on SW1 Gi0/2:

  • SW1 begins sending BPDUs out Gi0/2 advertising Designated Port ID 64.3.
  • SW2 compares 128.2 (received on Gi0/1) vs 64.3 (received on Gi0/2).
  • Because 64.3 < 128.2, SW2 immediately elects Gi0/2 as its Root Port and blocks Gi0/1.
  • Crucial Exam Takeaway: Port priority is evaluated on the sending (upstream) switch, not the receiving switch!

3. STP Timers & Propagation Rules

In classic STP (802.1D) and PVST+:

Timer Default Value Function Where Configured?
Hello Time 2 Seconds Interval between successive Hello BPDU transmissions generated by the Root Bridge. Root Bridge Only
Max Age 20 Seconds (10 x Hello) Time a switch waits before declaring a stored BPDU invalid after missing hellos. Root Bridge Only
Forward Delay 15 Seconds Time spent in the Listening state and Learning state before entering Forwarding. Root Bridge Only
Mathematical Timer Rules (IEEE 802.1D):
Cisco IOS enforces these strict formulas when tuning STP timers:
1. 2 × (Forward Delay - 1) ≥ Max Age (e.g., 2 × (10 - 1) = 18 ≥ 14 ✓)
2. Max Age ≥ 2 × (Hello Time + 1) (e.g., 14 ≥ 2 × (2 + 1) = 6 ✓)

4. Comparison: Classic STP (802.1D) vs Rapid STP (802.1w)

Feature IEEE 802.1D (Classic STP / PVST+) IEEE 802.1w (Rapid STP / Rapid-PVST+)
Convergence Speed 30 to 50 seconds (timer-based) Sub-second (1–2 seconds) via handshake
Port Roles Root, Designated, Blocking, Disabled Root, Designated, Alternate, Backup, Disabled
Port States Disabled, Blocking, Listening, Learning, Forwarding Discarding, Learning, Forwarding
BPDU Generation Only generated by Root; relayed by others Every switch generates BPDUs independently
Fast Transition Mechanisms None (relies on timers) Proposal / Agreement Handshake & Edge Ports

5. Common CCNA Exam Traps & Pitfalls

  • Trap 1 (Configuring Port Priority on the Wrong Switch): Configuring spanning-tree port-priority on SW2 changes the port ID that SW2 sends to its neighbors, which does NOT affect SW2's own Root Port selection. Always configure port priority on the upstream switch!
  • Trap 2 (Port Priority Increments): Cisco IOS only accepts port priority in multiples of 16. Entering spanning-tree port-priority 50 will be rejected by the CLI.
  • Trap 3 (Timer Mismatch): Tuning timers on a non-root switch has no effect because non-root switches overwrite their timers with the values in the Root Bridge's BPDUs. Always tune timers on the Root Bridge!
  • Trap 4 (Root Port Count): A non-root switch can have only ONE Root Port per VLAN, but a single switch can have multiple Designated Ports.
