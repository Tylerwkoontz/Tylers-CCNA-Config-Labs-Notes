🏢 Business Scenario

Your organization has acquired the network block 192.168.100.0/24. As the Network Associate, you are tasked with designing and configuring subnets for two branch locations:

  • Sales LAN (Site 1): Minimum 50 usable host endpoints.
  • Engineering LAN (Site 2): Minimum 25 usable host endpoints.
  • WAN Link (R1-R2): Exactly 2 usable IP addresses for point-to-point connection.

🗺️ Lab Topology

📋 Task 1: VLSM Subnet Calculation

Calculate your subnet boundaries before configuring devices.

💡 Hint: Subnet Sizing Hierarchy
Always allocate in order from largest to smallest host count:
  • Sales LAN (>=50 hosts) → Borrow 2 bits → /26 (62 usable hosts)
  • Engineering LAN (>=25 hosts) → Borrow 3 bits → /27 (30 usable hosts)
  • WAN Link (2 hosts) → Borrow 6 bits → /30 (2 usable hosts)
🔍 Solution: Verified Addressing Table
Subnet Name Subnet ID Mask / Prefix Usable Range Broadcast IP
Subnet A (Sales) 192.168.100.0 255.255.255.192 (/26) .1 – .62 192.168.100.63
Subnet B (Eng) 192.168.100.64 255.255.255.224 (/27) .65 – .94 192.168.100.95
Subnet C (WAN) 192.168.100.96 255.255.255.252 (/30) .97 – .98 192.168.100.99

🛠️ Task 2: Router 1 (R1) Configuration

  • Set hostname to R1
  • Configure Gi0/0 with IP 192.168.100.97 255.255.255.252 and description
  • Configure Gi0/1 with IP 192.168.100.1 255.255.255.192 and description
🔍 Solution: Router 1 CLI Commands 
enable
configure terminal
hostname R1
!
interface GigabitEthernet0/0
 description WAN Link to R2
 ip address 192.168.100.97 255.255.255.252
 no shutdown
!
interface GigabitEthernet0/1
 description Sales Department LAN Gateway
 ip address 192.168.100.1 255.255.255.192
 no shutdown
!
line con 0
 exec-timeout 0 0
 logging synchronous
!
end
write memory

🛠️ Task 4: Static Routing Configuration

  • Configure static route on R1 to reach Engineering LAN (192.168.100.64/27 via R2 IP 192.168.100.98)
🔍 Solution: Static Route Commands 
! On Router 1:
R1(config)# ip route 192.168.100.64 255.255.255.224 192.168.100.98

! On Router 2:
R2(config)# ip route 192.168.100.0 255.255.255.192 192.168.100.97
