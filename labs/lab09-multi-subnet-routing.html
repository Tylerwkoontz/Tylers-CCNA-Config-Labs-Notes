🗺️ Topology & Addressing Reference

Key Exam Takeaways:

  • Next-hop vs Exit Interface: In point-to-point links (like R1-R2), specifying the exit-interface (ip route 192.168.100.64 255.255.255.224 Gi0/0) works without ARP issues, but specifying the next-hop IP (192.168.100.98) is standard practice and mandatory on Ethernet multi-access networks.
  • Return Routing Trap: A ping will fail if the destination device or intermediate router lacks a return route back to the source subnet, even if the outbound path is 100% correct!
  • Local /32 Routes: Notice the L routes in show ip route. These are added automatically by Cisco IOS 15+ for the router's own interface IP.
