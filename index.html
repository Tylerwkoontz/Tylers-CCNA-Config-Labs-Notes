⚡ Part II Quick Ref: Cisco Memory Subsystems & CLI Shortcuts

4 Cisco Memory Types:

  • RAM (Volatile): Active running-config, MAC table, ARP table, routing table. Erased on reboot!
  • NVRAM (Non-Volatile): startup-config and config register. Retained on reboot.
  • Flash: Cisco IOS XE operating system image binary files.
  • ROM: Bootstrap loader, POST diagnostics, ROMMON recovery.

Essential CLI Navigation Shortcuts:

  • Ctrl+A / Ctrl+E: Jump to line beginning / end
  • Ctrl+U: Delete entire command line
  • Ctrl+Z or end: Exit directly to Privileged EXEC (#)
  • do <command>: Execute EXEC command from config submodes
