📖 Quick Chapter 09 Formulas & Gotchas (Click to Expand)
  • Number of Subnets ($s$ borrowed bits): $2^s$
  • Usable Hosts per Subnet ($h$ host bits): $2^h - 2$
  • Magic Number (Step Size): $256 - \text{Interesting Octet Mask Value}$
  • IOS 15+ Route Types: C = Connected Subnet (e.g. 10.1.1.0/24), L = Local Host Route for Interface IP (e.g. 10.1.1.1/32).
